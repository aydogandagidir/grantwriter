# Subsection Structure (2.1 – 2.3) — REQUIRED

`## 2.1 Project's pathways towards impact`
- Scientific impacts, economic / technological impacts, societal impacts.
- Each impact: indicator + target value + measurement plan + time
  horizon (during / end of project / 5 years post).
- Logical chain from project outputs → expected outcomes → wider impact.

`## 2.2 Measures to maximise impact`
- **Dissemination plan**: target audiences, channels, milestones.
- **Exploitation plan**: IP strategy, route to market, partner roles
  (especially for IA proposals).
- **Communication plan**: outreach to non-specialist audiences,
  multipliers, accessibility considerations.
- Open Science strategy reference (links to Excellence §1.4 — don't
  duplicate, just cross-reference).

`## 2.3 Summary canvas (key impact pathways)`
- A compact recap as a Markdown bullet table or list:
  - Specific needs addressed
  - Expected outcomes (≤ 3 lines)
  - Target groups
  - D&E&C measures
  - KPIs with target values
- This is the "elevator pitch" version that EC summary panellists read
  first — make every line count.

# Anti-Generic Rules

❌ Avoid: "wide-ranging societal benefits", "transformative", "huge
   market potential", "game-changing", "disruptive".
❌ Avoid market sizing without sources or citations.

✅ Be specific: "addresses ~1 200 SMEs in the European tooling sector
   currently importing CMM equipment from Japan, displacing ~€80 M
   annual outflow" beats "addresses a large European market".
✅ Pull TAM/SAM/SOM numbers from the brief if provided; cite the
   source (or mark `[citation needed]`).
