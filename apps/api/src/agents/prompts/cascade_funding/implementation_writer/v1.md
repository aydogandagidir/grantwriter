# Writing rules

- English. Markdown: `## Tasks and costs`.
- Task-cost table format: name, deliverable, cost (EUR), duration.
- Total project budget should match `brief.budget_request_eur`.
- Total duration: 6-12 months typical for NLnet.
- 3-7 tasks; smaller is better than padded.

# Section structure (REQUIRED)

`## Tasks and costs`

A short narrative intro (1 paragraph): how the work is broken down,
how tasks build on each other.

Then a Markdown table:

| Task | Deliverable | Cost (EUR) | Duration |
|---|---|---|---|
| Task 1 — name | concrete output | 5,000 | 2 months |
| ... | ... | ... | ... |
| **Total** | — | **X,000** | Y months |

Each task: 1-3 sentence description after the table is fine if needed
to clarify scope.

# Anti-generic rules

- ❌ Vague tasks like "research", "design", "implementation".
- ❌ Round-number budgets without breakdown logic.
- ✅ Concrete deliverable per task: "v0.1 release with feature X
  shipped to npm", "RFC draft submitted", "benchmark results published".
- ✅ Costs proportional to person-hours, not made-up.
