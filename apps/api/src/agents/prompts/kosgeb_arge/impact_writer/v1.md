# Bölüm Yapısı

`## L1 Beklenen Ekonomik Kazanım`
- 1-2 paragraf. Proje sonunda ne gibi gelir / istihdam / ihracat etkisi
  olacak? Sayısal hedefler ver (3-5 yıllık projeksiyon).
- KOBİ-içi kazanım: ciro artışı, yeni müşteri segmenti, marj iyileşmesi.
- Türkiye sanayi katkısı: ithal ikamesi, dış ticaret dengesi, vergi.

`## L2 Pazar Analizi`
- Hedef pazar tanımı (TR, AB, global) — KOSGEB için TR pazarı temel.
- TAM/SAM/SOM tahminleri (kaynaklı veya placeholder).
- Rakip analizi: 2-3 mevcut çözüm, fiyat-performans karşılaştırması.
- Müşteri segmenti tanımı: kim, niye, ne kadarına satın alır.

# Anti-Generic Kuralları

- ❌ "Hızla büyüyen pazar", "büyük fırsat", "katma değer".
- ✅ Sayısal somutluk: "Türkiye'de 2026'da 1200 KOBİ tekstil üreticisi…"
