### 2.2 Embedding Modeli

**Karar:** OpenAI `text-embedding-3-large` (3072 dim)

**Reasoning:**
- Multilingual (TR + EN, single index)
- 3072 dim = yüksek kaliteli semantic match
- pgvector HNSW index ile <200ms p95 retrieval
- $0.13/1M tokens = corpus için ucuz (50MB corpus ≈ $7 one-time)

**Alternatives değerlendirildi:**
- `text-embedding-3-small` (1536 dim, $0.02/1M): 4x ucuz ama kalite kaybı belirgin (test edildi)
- `BAAI/bge-m3` (open source, multilingual): self-hosted ama latency ve infra maliyeti yüksek
- Cohere `embed-multilingual-v3`: rakip, ama OpenAI sürdürülebilirliği için tercih edildi

### 2.3 Chunking Stratejisi

**Section-aware chunking:** Successful proposals "Excellence", "Impact", "Implementation" şeklinde ayrılır; her bölüm bağımsız chunk'lanır.

```python
# apps/api/src/rag/chunker.py
def chunk_proposal(text: str, section: str) -> list[Chunk]:
    """
    Section-aware semantic chunking.
    Target: 800-1200 tokens per chunk, with 200-token overlap.
    Boundaries respect paragraph and section breaks.
    """
    paragraphs = split_paragraphs(text)
    chunks = []
    current_chunk = []
    current_tokens = 0

    for para in paragraphs:
        para_tokens = count_tokens(para)

        if current_tokens + para_tokens > 1200:
            # Emit chunk
            chunks.append(Chunk(
                content="\n\n".join(current_chunk),
                section=section,
                metadata={"paragraph_count": len(current_chunk)}
            ))
            # Start new chunk with overlap (last paragraph)
            current_chunk = [current_chunk[-1]] if current_chunk else []
            current_tokens = count_tokens(current_chunk[-1]) if current_chunk else 0

        current_chunk.append(para)
        current_tokens += para_tokens

    if current_chunk:
        chunks.append(Chunk(content="\n\n".join(current_chunk), section=section))

    return chunks
```

### 2.4 Retrieval Flow

```python
# apps/api/src/rag/retriever.py

async def retrieve_for_excellence(
    brief: ProjectBrief,
    call: Call,
    k: int = 5,
) -> list[RetrievedChunk]:
    """
    Multi-step retrieval:
    1. Build query from brief + call
    2. Embed query
    3. Filter corpus by programme + section
    4. pgvector HNSW similarity search (top 20)
    5. Re-rank with LLM (top 5)
    """
    # Step 1: Construct query
    query = f"""
    Project: {brief.title}
    Topic: {call.topic_keywords}
    Approach: {brief.summary}
    Why this matters: {brief.problem_statement}
    """

    # Step 2: Embed
    embedding = await embed(query, model="text-embedding-3-large")

    # Step 3-4: pgvector search (filtered)
    candidates = await db.fetch_all("""
        SELECT spc.*, sp.title, sp.topic_id
        FROM successful_proposal_chunks spc
        JOIN successful_proposals_corpus sp ON spc.corpus_id = sp.id
        WHERE sp.programme_id = $1
          AND spc.section = 'excellence'
        ORDER BY spc.embedding <=> $2
        LIMIT 20
    """, call.programme_id, embedding)

    # Step 5: LLM re-rank (cheaper Sonnet model)
    reranked = await llm_rerank(query, candidates, top_k=k)

    return reranked
```

### 2.5 Re-ranking with LLM

```python
async def llm_rerank(query: str, candidates: list[Chunk], top_k: int = 5):
    """Use Claude Sonnet to re-rank candidates by relevance."""
    prompt = f"""Given the user's project query and these candidate text chunks
    from successful past proposals, rank them by relevance to the user's project.
    Output JSON: {{"ranked_ids": ["id1", "id2", ...]}}

    Query: {query}

    Candidates:
    {format_candidates(candidates)}
    """
    response = await llm.complete(prompt, model="claude-sonnet-4-6", max_tokens=500)
    ranked_ids = parse_json(response.text)["ranked_ids"][:top_k]
    return [c for c in candidates if c.id in ranked_ids]
```

## 3. Citation Grounding (CRITICAL)

### 3.1 Three-Stage Verification Pipeline

```
┌──────────────────────────────────────────────────────────────┐
│ STAGE 1: PRE-GENERATION (RAG-injected citations)             │
│                                                               │
│ When agent retrieves a chunk, every citation IN that chunk   │
│ is pre-verified (already in our corpus, all DOIs known).     │
│ Agent is instructed: "Only cite from provided sources."       │
│ → Reduces fabrication probability ~80%                       │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│ STAGE 2: POST-GENERATION (Hallucination Hunter)              │
│                                                               │
│ After draft generated, regex-extract all citations.           │
│ For each:                                                     │
│  1. Has DOI? → doi.org HEAD request                          │
│     ├─ 200 OK → fetch metadata, verify title match           │
│     └─ 404    → FLAG fabricated                              │
│  2. No DOI? → Crossref API title+author search               │
│     ├─ Match score >0.85 → ✓ verified, extract DOI           │
│     ├─ 0.50-0.85 → FLAG partial_match (user reviews)         │
│     └─ <0.50 → OpenAlex fallback                             │
│  3. OpenAlex no match → FLAG fabricated                       │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│ STAGE 3: USER-FACING UI                                       │
│                                                               │
│ Each citation in editor:                                      │
│  ✓ Green = verified (clickable DOI)                          │
│  ⚠️ Yellow = partial_match (user must review)                 │
│  ❌ Red = fabricated (BLOCKS export)                          │
│                                                               │
│ "Validate Compliance" button checks: 0 red citations         │
│ Otherwise export blocked.                                     │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 Implementation

```python
# apps/api/src/citations/verifier.py
import httpx
from rapidfuzz import fuzz

class CitationVerifier:
    def __init__(self, redis_client):
        self.redis = redis_client
        self.crossref = "https://api.crossref.org/works"
        self.openalex = "https://api.openalex.org/works"

    async def verify(self, citation: Citation) -> VerificationResult:
        # 1. Cache check
        cached = await self.redis.get(f"cite:{citation.cache_key()}")
        if cached:
            return VerificationResult.from_json(cached)

        # 2. DOI direct check
        if citation.doi:
            result = await self._verify_doi(citation)
            if result.status == "verified":
                await self._cache(citation, result, ttl=2592000)  # 30 days
                return result

        # 3. Crossref search
        result = await self._search_crossref(citation)
        if result.status in ("verified", "partial_match"):
            await self._cache(citation, result, ttl=2592000)
            return result

        # 4. OpenAlex fallback
        result = await self._search_openalex(citation)
        await self._cache(citation, result, ttl=2592000)
        return result

    async def _verify_doi(self, citation: Citation) -> VerificationResult:
        async with httpx.AsyncClient(timeout=5.0) as client:
            try:
                resp = await client.head(f"https://doi.org/{citation.doi}",
                                         follow_redirects=True)
                if resp.status_code == 200:
                    # Fetch metadata from Crossref
                    meta_resp = await client.get(f"{self.crossref}/{citation.doi}")
                    if meta_resp.status_code == 200:
                        meta = meta_resp.json()["message"]
                        title_match = fuzz.token_set_ratio(
                            citation.title or "", meta.get("title", [""])[0]
                        ) / 100
                        if title_match > 0.85:
                            return VerificationResult(
                                status="verified",
                                source="doi_direct",
                                metadata=meta,
                                match_score=title_match,
                            )
                        else:
                            return VerificationResult(
                                status="partial_match",
                                source="doi_direct",
                                metadata=meta,
                                match_score=title_match,
                                warning="DOI exists but title doesn't match",
                            )
                return VerificationResult(status="fabricated", source="doi_direct")
            except Exception as e:
                return VerificationResult(status="error", error=str(e))

    async def _search_crossref(self, citation: Citation) -> VerificationResult:
        # Build query
        query = citation.title or ""
        if citation.authors:
            query += " " + " ".join(citation.authors[:2])

        async with httpx.AsyncClient(timeout=10.0) as client:
            resp = await client.get(self.crossref, params={
                "query.bibliographic": query,
                "rows": 5,
                "mailto": "support@bluedev.dev",  # polite pool
            })
            if resp.status_code != 200:
                return VerificationResult(status="error")

            items = resp.json()["message"]["items"]
            if not items:
                return VerificationResult(status="not_found")

            # Find best match
            best = None
            best_score = 0
            for item in items:
                score = fuzz.token_set_ratio(
                    citation.title or "",
                    item.get("title", [""])[0]
                ) / 100
                if score > best_score:
                    best_score = score
                    best = item

            if best_score > 0.85:
                return VerificationResult(
                    status="verified",
                    source="crossref",
                    metadata=best,
                    match_score=best_score,
                )
            elif best_score > 0.50:
                return VerificationResult(
                    status="partial_match",
                    source="crossref",
                    metadata=best,
                    match_score=best_score,
                )
            else:
                return VerificationResult(status="not_found")
```

### 3.3 Hallucination Hunter Agent (Final Pass)

```python
# apps/api/src/agents/hallucination_hunter.py

async def run_hallucination_hunt(proposal_id: UUID) -> HuntReport:
    """
    Final agent — runs after all writers complete.
    1. Extract all citations from draft
    2. Verify each via CitationVerifier
    3. Cross-check claims vs RAG sources (semantic)
    4. Generate report
    """
    proposal = await get_proposal(proposal_id)

    # Step 1: Extract citations from all sections
    citations = []
    for section in ["excellence", "impact", "implementation"]:
        section_text = proposal.draft.get(f"{section}_md", "")
        citations.extend(extract_citations(section_text))

    # Step 2: Parallel verification (batch)
    verifier = CitationVerifier(redis)
    tasks = [verifier.verify(c) for c in citations]
    results = await asyncio.gather(*tasks)

    # Step 3: Claim verification (sample-based, expensive)
    # For each major claim with citation, ask LLM:
    # "Does this exact claim appear in this verified source?"
    claim_checks = await verify_claims_sample(proposal, results, sample_size=10)

    # Step 4: Generate report
    return HuntReport(
        total_citations=len(citations),
        verified=sum(1 for r in results if r.status == "verified"),
        partial=sum(1 for r in results if r.status == "partial_match"),
        fabricated=sum(1 for r in results if r.status in ("fabricated", "not_found")),
        claim_check_pass_rate=claim_checks.pass_rate,
        flagged_citations=[r for r in results if r.status != "verified"],
        recommendation="block_export" if any(r.status == "fabricated" for r in results) else "ok",
    )
```

## 4. Distinctiveness Scoring (Anti-Generic Output)

Nature Şubat 2026 bulgusu: AI-yazılı başvurular "lower semantic distinctiveness" sergiliyor → değerlendiriciler tarafından eleniyor (özellikle Avrupa).

### 4.1 Algorithm

```python
# apps/api/src/compliance/distinctiveness.py

async def score_distinctiveness(
    proposal: Proposal,
    threshold_high: float = 0.85,
    threshold_critical: float = 0.92,
) -> DistinctivenessScore:
    """
    Compare proposal's Excellence section to CORDIS funded projects
    in same topic. Higher cosine similarity = less distinctive.

    Scoring:
    - <0.85: distinctive (green)
    - 0.85-0.92: similar to existing (yellow warning)
    - >0.92: too generic, likely AI-generated patterns (red, suggest rewrite)
    """
    # Get user's Excellence section embedding
    excellence_text = proposal.draft.get("excellence_md", "")
    user_embedding = await embed(excellence_text)

    # Get CORDIS funded projects in same topic (last 3 years)
    matches = await db.fetch_all("""
        SELECT id, acronym, abstract, abstract_embedding,
               1 - (abstract_embedding <=> $1) AS similarity
        FROM cordis_funded_projects
        WHERE topic_id = $2
          AND start_date >= now() - interval '3 years'
        ORDER BY abstract_embedding <=> $1
        LIMIT 10
    """, user_embedding, proposal.call.external_id)

    if not matches:
        return DistinctivenessScore(
            score=None,
            level="unknown",
            message="No comparable funded projects found in CORDIS for this topic.",
        )

    top_similarity = matches[0]["similarity"]

    if top_similarity < threshold_high:
        level = "distinctive"
        message = f"Your proposal is sufficiently distinctive (max similarity: {top_similarity:.2f})."
    elif top_similarity < threshold_critical:
        level = "warning"
        message = f"Your proposal is similar to '{matches[0]['acronym']}' ({top_similarity:.2%}). Consider differentiating."
    else:
        level = "critical"
        message = f"⚠️ Your proposal is very similar to '{matches[0]['acronym']}' ({top_similarity:.2%}). Likely too generic — major rewrite recommended."

    return DistinctivenessScore(
        score=top_similarity,
        level=level,
        message=message,
        similar_projects=[
            {"acronym": m["acronym"], "similarity": m["similarity"]}
            for m in matches[:5]
        ],
    )
```

1. **ONLY cite sources provided in <retrieved_context>.** Do not invent citations.

## 6. Monitoring & Quality Metrics

### 6.1 Continuous Tracking

```sql
-- Materialized view: weekly citation quality
create materialized view weekly_citation_quality as
select
  date_trunc('week', verified_at) as week,
  count(*) filter (where status = 'verified') as verified,
  count(*) filter (where status = 'partial_match') as partial,
  count(*) filter (where status in ('fabricated','not_found')) as fabricated,
  round(100.0 * count(*) filter (where status = 'verified') / nullif(count(*), 0), 2)
    as verification_rate
from citations
where verified_at is not null
group by 1;

-- Alert if verification rate drops below 90%
```
